# 墨笺 · Word / Markdown 手写体转换器

将 Word `.docx`、Markdown 或 TXT 转为手写风格的 A4 PNG，也可直接导出单个 PDF。全部内容在本机处理；界面使用 Tkinter，Word 导入和字体管理使用 Python 标准库，PDF 使用现有 Pillow，没有增加第三方运行依赖。

## 开始使用

需要带 tkinter 的 Python 3.10+。下载仓库的 ZIP 并解压，在项目目录运行：

```bash
python -m pip install -r requirements.txt
python gui.py
```

Windows 请双击 **`启动GUI.vbs`**，直接打开 GUI，不显示终端。`启动GUI.bat` 保留为兼容转交入口。首次安装依赖需要网络；已有依赖和所需字体后可离线转写。

1. 选择字体或“工整笔记 / 自然手写 / 紧凑复习”预设。
2. 拖入 `.docx`、`.md`、`.markdown` 或 `.txt`，自动快速预览选中文档的第一页。
3. 调整参数后点击“快速预览第一页”，满意后点“确认生成全文”。
4. 在文件队列查看每份文件状态，双击查看结果和问题清单。
5. 需要打印时，将导出格式设为“PDF 文件”，只输出一个 PDF，不生成结果子文件夹。

窗口缩放时，界面文字、控件行高与侧栏会一起缩放，文档字号保持不变。设置会自动保存。正文位置/旋转随机度与字形变化强度独立：排版想整齐可将前者设为 0～0.2，后者设为 1～1.5。字形变化基于原字体，不会生成新的笔顺。

## 预览、批量与取消

- 预览在排满第一页时停止绘制，后面的页面和公式不会继续排版；读取文件和解析正文仍需进行。
- 选择文件不会生成全文或正式输出；修改参数、输入文件或输出设置后需重新预览确认。
- 单击队列中的文件，再点快速预览，可以切换预览对象。首个文件损坏时可先预览其他文件。
- 每份文件独立执行，一个失败后继续后续文件；“只重试失败项”不会重做成功文件。
- “取消当前批次”停止当前转换和待执行任务；排版逐字检查取消，PDF 逐页检查。已经完成的文件保留。
- 全文转换逐页写盘，避免把所有 A4 图片同时保存在内存中。
- 页码框可直接跳页，“刷新当前页”复用未失效的页面；双击预览或点击“局部放大”后用滚轮缩放、拖动平移。
- 缓存最多保留三组输入/参数，依据文档、参数、引用图片和字体内容失效。未缓存的后页需要从开头排版到该页，不继续排版全文。
- 问题清单区分错误、警告、替代显示，记录源行、章节、对象与页码；双击问题可跳页。PNG 另存 JSON/TXT 清单，单文件 PDF 不增加伴随文件。

## 表格、示意图与方框答案

- Markdown 表格按网格绘制，单元格支持文字与数学公式；自动换行，跨页重复表头。
- Word 表格在实际转写时也保留表格结构；复杂合并单元格按文字网格展开。
- 围栏中的字符示意图不再删除。`text` / `ascii` / `diagram` / `polezero` 中的坐标轴、边界线、箭头、× 和 ○ 会按原文位置绘制，中文标签保留。
- 支持 `\boxed{...}` / `\fbox{...}`，包括并列方框和 aligned 中的方框答案。
- 高公式按真实高度排版，避免方框或根号碰到前后文字。
- 支持单独一行的本地 Markdown 图片，相对路径以源文件目录为准；等比缩放并将替代文字作为图注。缺失图片显示占位并报错。
- `plot` 围栏接受严格 JSON 坐标描述，使用 Pillow 绘制，无需新依赖，参见 [精确绘图说明](docs/精确绘图.md)。不运行 Python、JavaScript 或其他文档代码。
- 正文、公式、表格文字和图形的变化强度独立；三个预设默认让公式、表格与图形保持规整。
- 自动限制超宽/超高对象、保护页底标题，检查内容区域重叠和边界，提示过密表格、缺字及图与说明跨页。它不验证数学结论，也不能替代视觉检查。

这是对字符示意图的重绘，不会识别截图、扫描图或任意绘图脚本。复杂 LaTeX 不支持时仍会列出问题，供核对。

## 输出管理

**PDF 模式**：选择“PDF 文件”或命令行 `--pdf`，只在指定目录生成一个与源文档同名的 PDF。未指定目录时直接保存到源文件旁；不生成 PNG、问题清单或结果子文件夹。预览图片仅在临时缓存中，退出后清理。问题在界面清单中查看，也写入 PDF 属性的关键字。

重新生成会原子替换本工具为同一源文件生成的 PDF，失败或取消保留上次完整结果。若存在不属于本工具或不同源文件的同名 PDF，会自动使用带路径摘要的名称，避免覆盖。

**PNG 模式**：默认在源文件旁的 `手写体/` 或指定根目录下使用独立文档目录与版本目录。成功后更新 `latest.json`，只清理上次记录的生成文件，用户自行加入的文件保留。升级前旧版输出不会自动删除。

PDF 是图片型 PDF，与预览页序一致，按渲染 DPI 写入 A4 尺寸，适合打印，不含可搜索文字层。

## Word 支持

- 支持正文、标题、列表、超链接文字及表格文字，按文档顺序转写。
- 表格保留文字网格，列表统一为项目符号，不复刻原始 Word 页面和编号。
- 支持常见原生分式、根号、上下标、求和、积分、矩阵和分段函数。
- 不支持的原生公式、渲染失败的公式、图片和嵌入对象会列入问题清单，包含段落/表格行列、公式序号或片段。
- 图片公式、图片内容、页眉页脚、原页码不转写；复杂公式仍需核对。
- 旧版 `.doc` 请先用 Word / WPS 另存为 `.docx`；加密文件需先解除加密。

## 字体按需下载

基础版只附带 **霞鹜文楷、马善政墨韵**，共约 30.3 MiB。其余 10 个选项在“字体管理”查看样张、文件大小、官方来源与 OFL 授权，点击后下载。

下载使用固定版本并校验大小与 SHA-256，通过后原子安装到用户缓存；下载失败/取消不会替换已有字体。已安装字体可离线使用。旧版本本地已有的可选字体仍可识别，无需重下。

可选字体：龙藏体、六剑毛笔草、志莽行书、站酷快乐体、小赖字体、悠哉细体/常规/中等、霞鹜漫黑、霞鹜臻楷。自然手写预设在小赖尚未安装时先使用文楷，下载后可自行选择小赖。

[字体来源与授权](fonts/README.md) · [字体清单与校验值](fonts/catalog.json)

为避免下载旧字体包的 Git 历史，分享时建议用 GitHub 的 Download ZIP，或：

```bash
git clone --depth 1 https://github.com/LeoLi006/handwriting-tool.git
```

## 命令行

```bash
python handwriting.py --list-fonts
python handwriting.py "课堂笔记.docx" --jitter 0.2 --glyph-variation 1 --pdf -o output
python handwriting.py "examples/示例.md" --max-pages 1
```

`--max-pages` 和 `--page` 已会提前停止后续页的排版。`--pdf` 只导出一个图片型 PDF，不输出结果文件夹。命令行与界面共用对应格式的安全发布机制。

完整参数、设置位置和故障排查见 [使用说明书](使用说明书.md)。

## 开发与验证

字符图保留显式线型：`─ │` 为实线，`┄ ┈ ╌ ┆ ┊ ╎` 为虚线，交叉处分别保留各方向线型。全部使用实线字符的输入会保持实线；“虚部门限”表示虚部的门限，不是虚线标记。参见 [实线与虚线示例](examples/实线与虚线.md)。

```bash
python -m unittest discover -s tests -v
python tools/run_regression.py --output output/regression
python tools/check_gui.py
python tools/build_portable.py
```

回归入口：[原创综合 Markdown](examples/regression/综合回归.md)、[逐项检查记录](docs/综合回归检查.md)。`build_regression_sample.py` 可重新生成同样的 Markdown 和三张原创本地图片。回归命令分别导出 PNG、单文件 PDF，验证首页一致与缓存命中；安装 Poppler 后可加 `--poppler 路径` 检查所有 PDF 页面。仍需逐页核对视觉结果。

分享命令输出 `dist/handwriting-tool-base.zip` 和大小/校验清单，仅携带两款基础字体、代码、说明与原创样本，不含 Git 历史、可选字体、Python 或运行依赖。完整解压后双击 `启动GUI.vbs`。接收者需先安装带 tkinter 的 Python 3.10+；首次补齐依赖/下载可选字体需要联网，之后可离线使用。不是免 Python 的独立 EXE。已移除未使用的 handright 依赖。

核心模块：`gui.py`（界面）、`app_settings.py`（设置/预设）、`handwriting.py`（排版）、`batch_tasks.py`（批量任务）、`managed_output.py`（结果发布）、`word_reader.py`（Word）、`formula.py`（公式）、`font_manager.py`（字体）、`pdf_export.py`（PDF）。

无终端启动相关模块：`启动GUI.vbs`、`launch_gui.ps1`、`gui_launcher.py`。表格和示意图由 `table_render.py`、`structured_content.py` 处理；界面字体缩放由 `ui_scaling.py` 处理。

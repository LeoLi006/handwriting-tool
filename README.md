# 墨笺 · Word / Markdown 手写体转换器

将 Word `.docx`、Markdown 或 TXT 转为手写风格的 A4 PNG，并可同时导出整份 PDF。全部内容在本机处理；界面使用 Tkinter，Word 导入和字体管理使用 Python 标准库，PDF 使用现有 Pillow，没有增加第三方运行依赖。

## 开始使用

需要 Python 3.9+。下载仓库的 ZIP 并解压，在项目目录运行：

```bash
python -m pip install -r requirements.txt
python gui.py
```

Windows 可双击 `启动GUI.bat`。首次安装依赖需要网络；已有依赖和所需字体后可离线转写。

1. 选择字体或“工整笔记 / 自然手写 / 紧凑复习”预设。
2. 拖入 `.docx`、`.md`、`.markdown` 或 `.txt`，自动快速预览选中文档的第一页。
3. 调整参数后点击“快速预览第一页”，满意后点“确认生成全文”。
4. 在文件队列查看每份文件状态，双击查看结果和问题清单。
5. 需要打印时，将导出格式设为“PNG + PDF”。

设置会自动保存。正文位置/旋转随机度与字形变化强度独立：排版想整齐可将前者设为 0～0.2，后者设为 1～1.5。字形变化基于原字体，不会生成新的笔顺。

## 预览、批量与取消

- 预览在排满第一页时停止绘制，后面的页面和公式不会继续排版；读取文件和解析正文仍需进行。
- 选择文件不会生成全文或正式输出；修改参数、输入文件或输出设置后需重新预览确认。
- 单击队列中的文件，再点快速预览，可以切换预览对象。首个文件损坏时可先预览其他文件。
- 每份文件独立执行，一个失败后继续后续文件；“只重试失败项”不会重做成功文件。
- “取消当前批次”停止当前转换和待执行任务；排版逐字检查取消，PDF 逐页检查。已经完成的文件保留。
- 全文转换逐页写盘，避免把所有 A4 图片同时保存在内存中。

## 输出管理

默认输出根目录为源文件旁的 `手写体/`；自定义目录作为根目录使用。

```text
手写体/
└── 笔记--源路径摘要/
    ├── latest.json
    └── run-本次版本号/
        ├── 笔记_p1.png
        ├── 笔记_p2.png
        ├── document.pdf       # 选择 PNG + PDF 时
        ├── 问题清单.txt
        └── .generation.json
```

同名但不同路径的文件使用不同目录。新版本全部成功后才切换 `latest.json`；取消、失败时保留上次完整结果。成功后只删除上次清单记录的生成文件，旧的多余页不会混入新版本；用户自行添加的文件不删除。升级前旧版直接输出的 PNG 不会自动删除，请自行确认后清理。

PDF 是图片型 PDF，与 PNG 页序一致，按渲染 DPI 写入 A4 尺寸，适合打印；不提供可搜索文字层。

## Word 支持

- 支持正文、标题、列表、超链接文字及表格文字，按文档顺序转写。
- 表格按行展开为文字，列表统一为项目符号，不复刻原始 Word 页面和编号。
- 支持常见原生分式、根号、上下标、求和、积分、矩阵和分段函数。
- 不支持的原生公式、渲染失败的公式、图片和嵌入对象会列入问题清单，包含段落/表格行列、公式序号或片段。
- 图片公式、图片内容、页眉页脚、原页码不转写；复杂公式仍需核对。
- 旧版 `.doc` 请先用 Word / WPS 另存为 `.docx`；加密文件需先解除加密。

## 字体按需下载

基础版只附带 **霞鹜文楷、马善政墨韵**，共约 30.3 MiB。其余 10 个选项在“字体管理”查看样张、文件大小、官方来源与 OFL 授权，点击后下载。

下载使用固定版本并校验大小与 SHA-256，通过后原子安装到用户缓存；下载失败/取消不会替换已有字体。已安装字体可离线使用。旧版本本地已有的可选字体仍可识别，无需重下。

可选字体：龙藏体、六剑毛笔草、志莽行书、站酷快乐体、小赖字体、悠哉细体/常规/中等、霞鹜漫黑、霞鹜臻楷。自然手写预设在小赖尚未安装时先使用文楷，下载后可自行选择小赖。

[字体来源与授权](fonts/README.md) · [字体清单与校验值](fonts/catalog.json)

为避免下载旧字体包的 Git 历史，分享时建议用 GitHub 的 Download ZIP，或：

```bash
git clone --depth 1 https://github.com/LeoLi006/handwriting-tool.git
```

## 命令行

```bash
python handwriting.py --list-fonts
python handwriting.py "课堂笔记.docx" --jitter 0.2 --glyph-variation 1 --pdf -o output
python handwriting.py "examples/示例.md" --max-pages 1
```

`--max-pages` 和 `--page` 已会提前停止后续页的排版。`--pdf` 同时导出整份图片型 PDF。命令行使用相同的独立目录和安全发布机制。

完整参数、设置位置和故障排查见 [使用说明书](使用说明书.md)。


## 验证边界

完整逐页检查关注数学项顺序、二维公式、长表末尾、图注及分页，PNG/PDF 页数和尺寸匹配，首页预览与最终 PNG 一致。PDF 的 JPEG 编码与 Poppler 抗锯齿会产生像素差，不能把像素差小或不报错当作数学正确的证明。

Windows 包只在同一台 Windows x64 主机做隔离环境验证，未提供干净虚拟机或第二台机器。系统 DLL、基础界面字体、操作系统组件仍来自这台主机。没有验证 ARM、32 位 Windows、所有安全软件或受限企业环境，不宣称完全可移植。Python 网络审计阻断的是测试进程的 Python 网络 API，不等同于防火墙隔离整台机器。

公式分行是保守的 TeX 子集，不推导等价式；复杂宏或无法可靠判断的分组保留原文/缩放并提示。超长组合降级后可能分离较早的说明；显式图注与图的可容纳组合仍保持。极端窄表保留字段显示替代。文档身份不可靠时不自动恢复到另一份文件；用户可重新选择并保存设置。

可重复入口：`tools/run_regression.py`、`tools/check_gui.py`、`tools/render_comparison.py`、`tools/check_document_profiles.py`、`tools/build_portable.py`、`tools/build_windows.py`、`tools/verify_windows.py`。更新固定依赖须显式重建锁并重新运行验证。测试记录使用相对路径，转换清单源身份采用摘要，诊断仅记录源文件名；不把完整私人目录写进交付记录。

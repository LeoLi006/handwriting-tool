# 安全的精确坐标图

在 Markdown 中使用 `plot` 围栏，内容必须是 JSON。它只描述坐标和样式，不是可执行语言。图形由现有 Pillow 绘制；不启动解释器、不下载资源。

```plot
{"xlim":[-4,4],"ylim":[-3,3],"axes":true,"points":[{"x":-2,"y":1,"kind":"zero","label":"z1"},{"x":2,"y":-1,"kind":"pole","label":"p1"},{"x":1,"y":1,"kind":"star"}],"lines":[{"from":[-2,-3],"to":[-2,3],"style":"dashed"},{"from":[-4,2],"to":[4,2],"style":"dashed"}],"labels":[{"x":0.2,"y":2.7,"text":"Q"},{"x":3.6,"y":-0.3,"text":"I"}]}
```

| 字段 | 含义 | 默认值 / 限制 |
|---|---|---|
| `xlim`, `ylim` | 坐标范围，两元素数组 | `[-4,4]` / `[-3,3]`，上限大于下限 |
| `axes` | 画过原点的实线箭头坐标轴 | `true`；范围不含零时不画该轴 |
| `points` | 点数组，各项含 `x`, `y`, `kind`, 可选 `label` | `zero` 空心零点、`pole` 叉号极点、`star` 实心星座点 |
| `lines` | 线段数组，各项含 `from`, `to`, 可选 `style` | `solid` 实线、`dashed` 虚线、`dotted` 点线 |
| `labels` | 标签数组，各项含 `x`, `y`, `text` | 普通文字，不解析公式 |

所有坐标必须是有限数字，绝对值不超过 1e9；点、线端点必须位于范围内。每种对象最多 500 项；标签不超过 80 字，越界标签报错。横纵方向使用相同的单位长度，坐标与角度不会因矩形画布而拉伸；范围按比例居中留白。暂不支持曲线、自动刻度、曲面、自动标签避让和数学标签。

判决门限需要显式指定 `dashed` 等线型。“虚部门限”是数学含义，不代表虚线。未知字段（例如 `run`）、非法范围、非法点类型、网络资源等不会被当成脚本执行；整个图显示错误占位，清单记录来源和原因。发生错误时不会提交一张看似正确但内容残缺的图。

原有字符图继续可用：横向实线 `─`、虚线 `┄ ┈ ╌`，竖向实线 `│`、虚线 `┆ ┊ ╎`。交点 `┼` 的各方向继承相邻线型。字符图受原始空格和字符列位置限制；需要确定坐标时使用 JSON。

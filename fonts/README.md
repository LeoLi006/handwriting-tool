字体的授权与项目代码分别适用。再分发时保留原始授权及版权说明。程序可能生成 `_merged_*.ttf` 符号回退缓存，缓存不随仓库分发。

原有字体包括霞鹜文楷、马善政墨韵、龙藏体、六剑毛笔草、志莽行书和站酷快乐体。
